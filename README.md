# 🪖 Veteran Analytics Project Overview

## About the Project

**Veteran Analytics** is a dual-repository, closed-source software initiative created and maintained by [Gillon Marchetti](https://www.linkedin.com/in/gillonmarchetti/), a U.S. Army veteran, federal policy analyst, and public interest technologist. The project is designed to deliver secure, intelligent tools to transform how veterans' benefits claims are analyzed, managed, and adjudicated—starting from deep backend automation through VALOR Core and extending to a user-facing interface with Veteran Analytics.

This repository serves as the centralized overview and daily development log for the project.
